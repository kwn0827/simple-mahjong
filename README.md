# 🀄 超やさしい1人麻雀 (Unicode Mahjong)

麻雀のルールを1ミリも知らない「ミリしら」の人でも、遊びながら形を覚えられる超親切設計のブラウザ麻雀ゲームです。
複雑な役の計算や鳴き（ポン・チー）を排除し、手札を揃える楽しさに特化しています。

👉 **[今すぐブラウザでプレイする](https://kwn0827.github.io/simple-mahjong/)**

---

## ✨ 特徴

- **超親切な初心者ガイド**: 
  現在の状況や、次に何を狙えばいいかのヒントがリアルタイムで画面に表示されます。
- **サクサク動くNPC対戦**: 
  対戦相手（CPU）3人が自動で牌を処理。自分のペースでじっくり考えながらプレイできます。
- **豪華なカジノ風ビジュアル**: 
  Unicodeの麻雀牌をCSSで立体的に表現。高級感のある全自動卓のようなデザインでゲームを盛り上げます。
- **役なしでもアガれる**: 
  「4面子1雀頭（3枚組×4、2枚ペア×1）」の基本形さえ揃えば、難しい役を覚えていなくても「アガリ（勝利）」になります。

---

## 🎮 遊び方・ルール

麻雀のゴールは、手元の**14枚**を使って決まった形を誰よりも早く完成させることです。

1. **牌を引いて捨てる**: 
   自分の番が来ると、右側に「ツモ牌（新しく引いた牌）」が表示されます。手牌の中からいらない牌を1つクリックして捨ててください。
2. **目指す形**:
   - **同じ牌を3枚**（例：🀇🀇🀇）または **連続した数字を3枚**（例：🀙🀚🀛）を**4セット**
   - **まったく同じ牌を2枚**（例：🀄🀄）を**1セット**
   - 合計「3+3+3+3 + 2 = 14枚」が綺麗に揃えばあなたの勝ちです！
3. **勝利**: 
   形が完成すると画面に大きく「アガリ！」のエフェクトが表示されます。
